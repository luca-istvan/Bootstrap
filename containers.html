Containers no Bootstrap

Entenda como organizar o espaço de uma página web

O que são containers?

Containers são elementos utilizados para organizar e centralizar o conteúdo de uma página. No Bootstrap, existem diferentes classes que controlam a largura do conteúdo conforme o tamanho da tela.

.container

Container padrão

Possui largura máxima definida conforme o tamanho da tela e centraliza o conteúdo.

Área centralizada
.container-fluid

Container fluido

Ocupa 100% da largura disponível da tela.

Área de largura total
.container-sm

Container SM

Ocupa toda a largura em telas menores e limita a largura a partir de 576px.

Exemplo de container SM
.container-md

Container MD

Limita a largura a partir de telas médias, com breakpoint de 768px.

Exemplo de container MD
.container-lg

Container LG

Limita a largura a partir de telas grandes, com breakpoint de 992px.

Exemplo de container LG
.container-xl

Container XL

Limita a largura a partir de telas extragrandes, com breakpoint de 1200px.

Exemplo de container XL
.container-xxl

Container XXL

Limita a largura a partir de telas muito grandes, com breakpoint de 1400px.

Exemplo de container XXL
